#  AI Edge Estimator

Calculadora de viabilidade para execução de Large Language Models (LLMs) em máquinas locais, com foco em **Edge Computing**.

## Objetivo

Estimar se um modelo de IA pode ser executado localmente com base nos recursos de hardware disponíveis, auxiliando decisões de arquitetura antes da implementação.

## Funcionalidades

- Estimativa de memória RAM e VRAM necessária.
- Análise de viabilidade com base nas especificações do hardware.
- Consideração de diferentes tamanhos de modelos e níveis de quantização.
- Indicação de possíveis limitações para execução local.

## Tecnologias

- Python

## Como executar

```bash
git clone <url-do-repositorio>
cd ai-edge-estimator
python main.py
```

> Ajuste o comando de execução conforme o nome do arquivo principal do projeto.

## Aplicações

- Avaliação de infraestrutura para LLMs locais.
- Planejamento de soluções de IA em dispositivos Edge.
- Comparação de configurações de hardware.
- Redução de custos com infraestrutura em nuvem.

## Objetivo técnico

Transformar requisitos de modelos de linguagem em estimativas práticas de hardware, tornando decisões sobre execução local de IA mais rápidas e fundamentadas.
